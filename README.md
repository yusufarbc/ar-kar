## 📋 Proje Hakkında

AR-KAR İnşaat için geliştirilmiş kurumsal web sitesi. Samsun Çarşamba'da 36 yıldır hizmet veren firmamızın hizmetlerini tanıtan responsive web sitesidir.

### Ana Özellikler

- Responsive tasarım
- SEO optimizasyonu
- Modern kullanıcı arayüzü
- Hızlı yükleme

## 🏢 Hizmet Alanları

### İnşaat & Mimarlık
- Konut İnşaat Projeleri
- Anahtar Teslim İnşaat
- Mimari Proje Hizmetleri
- Hırdavat & İnşaat Malzemeleri
- PVC Kapı ve Pencere Sistemleri
- Dekorasyon Hizmetleri

### Tarım & Ziraat
- Tarım Ürünleri Alım Satımı
- Zirai İlaç, Gübre ve Tohum
- Tarımsal Danışmanlık Hizmetleri

### Otomotiv
- İkinci El Araç Alım Satım
- Binek ve Ticari Araç Satışı

## Teknoloji

- **HTML5 & CSS3**
- **Bootstrap 5**
- **JavaScript & jQuery**
- **Font Awesome** - Icon library
- **Owl Carousel** - Image sliders

## 📁 Dosya Yapısı

```
ar-kar/
├── index.html              # Ana sayfa
├── projeler.html           # İnşaat projeleri
├── muteahhitlik.html       # Anahtar teslim hizmetler
├── insaat.html             # İnşaat malzemeleri
├── pvc.html                # PVC sistemler
├── tarim.html              # Tarım ürünleri
├── ziraat.html             # Zirai ürünler
├── otomotiv.html           # Otomotiv hizmetleri
├── mimar.html              # Mimari projeler
├── dekorasyon.html         # Dekorasyon hizmetleri
├── css/                    # Stil dosyaları
├── img/                    # Resim dosyaları
├── js/                     # JavaScript dosyaları
└── lib/                    # Kütüphaneler
```
