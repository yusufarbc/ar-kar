## 📋 Proje Hakkında

AR-KAR İnşaat, Gıda, Tarım Ürünleri ve Taş. Tic. Ltd. Şti. için geliştirilmiş modern ve responsive kurumsal web sitesi. Samsun Çarşamba'da 36 yıldır hizmet veren firmamızın tüm hizmetlerini dijital platformda tanıtan profesyonel bir web çözümüdür.

### 🎯 Ana Özellikler

- **Responsive Tasarım**: Tüm cihazlarda mükemmel görünüm
- **SEO Optimizasyonu**: Arama motorları için optimize edilmiş yapı
- **Hızlı Yükleme**: Optimize edilmiş resimler ve kodlar
- **Modern UI/UX**: Kullanıcı dostu arayüz tasarımı
- **Erişilebilirlik**: WCAG standartlarına uyumlu
- **PWA Hazır**: Progressive Web App desteği

```
│   ├── carousel-*.webp        # Slider resimleri
│   ├── about.webp             # Hakkımızda resmi
│   └── *.webp                 # Diğer optimize edilmiş resimler
├── 📜 js/
│   └── main.js                # Ana JavaScript dosyası
└── 📚 lib/                    # Üçüncü parti kütüphaneler
    ├── owlcarousel/           # Carousel kütüphanesi
    ├── lightbox/              # Lightbox kütüphanesi

    ├── waypoints/             # Scroll animations
    └── isotope/               # Grid filtering
```

## 🔧 Kurulum ve Geliştirme

### Yerel Geliştirme

```bash

git clone https://github.com/yusufarbc/ar-kar.git

# Proje dizinine gidin
cd ar-kar

# Local server başlatın (Python örneği)

# Tarayıcıda açın
```
